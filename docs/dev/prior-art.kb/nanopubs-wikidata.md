# Nanopublications and Wikidata ranks

Claim-grain publication with mandatory provenance. A nanopublication is
three named graphs — assertion, provenance, publication info — each
addressable; Wikidata statements carry ranks and references at web
scale.

**Gems:**

- Trusty URIs: nanopub identity is a content hash of the artifact —
  HASH_ID arrived at independently, for the same reason (citation must
  survive infrastructure).
- Ranks (preferred / normal / deprecated) with nothing ever deleted:
  standing as data, deprecated statements still queryable.
- Provenance as a separate mandatory graph, not an optional annotation —
  who asserted, from what method or source.

**Informs:** HASH_ID, STATUS, NAME_THE_JUDGE!;
`../user-stories.kb/veto-scan-agent-claims.md` (standing must live in
the value).

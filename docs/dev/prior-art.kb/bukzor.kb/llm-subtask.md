# llm-subtask — obligations as files

`Skill(llm-subtask)`: four-tier obligation tracking, conversational
markers through `todo.md` checkboxes to dated `todo.kb/` files, with
"default to the lightest tier that fits" as the governing rule. The
corpus's obligation surface, running daily in every repo of the fleet.

**Gems:**

- Capture cost priced per obligation weight: a marker is free, a
  checkbox cheap, a file deliberate — the ceremony gradient that
  `planning-framework` lacked, applied to debt.
- Dated-slug identity (`YYYY-MM-DD-NNN-title`) gives strategic items
  stable, sortable names — provenance in the filename.
- Successor task-class contracts: each class states whether pickup is
  an obligation or an option — "forgetting is a valid end state" for
  the lightest tier. Obligation semantics priced per tier, stated
  rather than assumed.

**Miss:** obligations are stored, not derived. The epistemics realm's
own revision (obligation-is-derived-not-stored): open debt should fall
out of the claim graph — every `?` is a todo — not be double-booked in
a parallel system that can drift from it.

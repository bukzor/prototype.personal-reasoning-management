# ACL2

Adequate on tooling, wrong on logic. Never a pleasure, and `CORPUS` is the
deciding objection.

- **CI**: the sleeper strength — `cert.pl` parallel certification is mature and
  fast, and books cache well.
- **CLI**: the REPL loop is decent if you metabolize Common Lisp.
- **Command surface**: the most foreign embedding of the five — everything
  through `encapsulate` / `defthm` macros over an untyped logic.
- **Corpus fit**: an untyped first-order logic is a poor host for
  dependently-typed-language metatheory, which is what `CORPUS` commits to.

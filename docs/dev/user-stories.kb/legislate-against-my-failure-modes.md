# Legislate against my own failure modes

I notice a recurring reasoning error of mine — acting on defeated
premises, say — and outlaw it. The law is a theorem about the claim set;
violating it fails the build; and adding a law is an afternoon's work, not
a project.

**Served by:** LAW, META_DEPTH, CHECKER_COLLAPSE, SELF_APPLY.

> [!QUESTION] is law-authoring-in-Lean a recorded trade?
> Authoring a law is the one workflow that requires writing engine code
> rather than markdown. Laws are rare and claims are daily, so the trade
> reads right — but it should be recorded as accepted (a `host` claim or a
> clause of LAW), not discovered by the first user who tries.

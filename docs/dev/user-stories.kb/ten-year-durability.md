# Ten-year durability

A decade on, on a new machine and a new toolchain, the corpus still means
what it meant. Toolchain bumps re-baseline hashes and demand fresh
verdicts — they never silently repair old ones. An external checker can
re-verify the corpus whole. And if the engine itself is gone, the kb
files alone still read as a complete record, because the round-trip
guarantees the surface is total.

**Served by:** VERSION_OUT+, AUDIT_SPOKE, SURFACE_SPLIT, NO_SIDECAR,
UNTRUSTED_XLATE (the round-trip is what makes the markdown a standalone
archive).

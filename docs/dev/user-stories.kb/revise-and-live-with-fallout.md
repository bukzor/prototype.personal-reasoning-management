# Revise a stipulation and live with the fallout

I withdraw or amend a stipulation. Everything downstream — transitively —
shows stale, enumerable in one query. Then I re-adjudicate *over days*, at
my own pace, while continuing to capture new claims and use the system.
Revision must be routine, not punitive: a system that punishes honest
revision teaches me to stop revising, which defeats the defeasibility
premise entirely.

# prototype.personal-reasoning-management

A framework for defeasible claims and their mandates, authority, and
proofs, built in Lean 4.

The claim ledger is a first-class Lean value generated from plain-markdown
knowledge bases; laws about the claim set are theorems the kernel checks.

- Design rationale, in prose: `docs/dev/design-sketch.md`
- Design ledger — the labelled claims the design commits to:
  `docs/dev/design.ledger.md`
- User stories — the demands the design must serve:
  `docs/dev/user-stories.kb/`
- Prior art: `docs/dev/prior-art.kb/`
